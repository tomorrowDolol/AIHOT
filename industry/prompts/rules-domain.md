
【称重行业翻译规则 — 本站内容全部与家用和商用称重测量有关，严格遵守】

1. 歧义默认值：以下词在中文有非称重歧义，**一律按称重与测量含义翻译**：
   - Scale / scales = 秤（不译“规模”“缩放”）
   - Body composition = 体成分（不译“身体组成”以外的含义）
   - BIA / Bioelectrical impedance analysis = 生物电阻抗分析（BIA 可保留英文）
   - Load cell = 称重传感器（不译“负载单元”）
   - Strain gauge = 应变片
   - Calibration = 校准（不译“标定”以外的含义，首次出现可写“校准”）
   - Accuracy = 精度 / 准确度；Resolution = 分度值 / 分辨率
   - Tare = 去皮；Zero = 归零
   - Recall = 召回（不译“回忆”）
   - Certification = 认证；Approval = 型式批准
   - Platform = 平台（渠道语境），不要译成“站台”
   - Channel = 渠道（销售语境）

2. 以下专有名词**一律保留英文原文**，不翻译不加中文括注：
   - 品牌：SENSSUN / CAMRY / Withings / Tanita / Omron / InBody / Fitbit / Garmin / Renpho / Etekcity / arboleaf / Xiaomi / HUAWEI / HONOR
   - 型号与版本：任何字母数字型号（如 EB8504H、F1、HBF-375）一字不改
   - 技术缩写：BIA / BLE / SoC / AFE / MCU / OTA / App / API / SKU / BOM / PCN / EOL / RoHS / REACH / MDR / FDA / FCC / CE / OIML / CPA / UN38.3
   - 认证与标准编号：EN 71、IEC 62368、ISO 9001 等原样保留
   - 单位与数字：0.1 kg / 180 kg / 5 mm / ±0.2 kg / 99.9% 原样保留，不换算、不改成中文数量词

3. 中国厂商**优先用官方中文品牌名**（首次出现可双标）：
   - 香山（SENSSUN / CAMRY）/ 小米（米家）/ 华为 / 荣耀 / 沃莱 / 云麦 / 乐心 / 芯海 / 泰凌微 / 乐鑫 / 巨微
   - 国外品牌保留英文：Withings / Tanita / Omron / InBody / Fitbit / Garmin / Renpho / Etekcity / arboleaf

4. 代码 / 命令 / URL / 数字单位 **一字不改**保留：
   - 反引号代码 `code` 不翻译
   - 命令、型号、认证编号不译
   - URL 原样
   - 金额、量程、精度、比例、区间必须保留原文的阿拉伯数字和单位；不要把 $10-$20 改写成“十几到二十美元”等中文数量词

5. 渠道名按读者熟悉的写法：Amazon 保留英文，天猫、京东、拼多多、抖音、TikTok Shop 按原文；线下渠道写“线下渠道”。
